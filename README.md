# Portafolio de Bruno Quispe

Portafolio personal de Bruno Quispe Sanabria, ingeniero de software con experiencia en soluciones web y aplicaciones móviles para procesos académicos y de negocio.

## Tecnologías del proyecto

- Angular CLI 13.3.11 y Angular 13.3.x
- TypeScript 4.6.x
- Node.js 18.20.8 y npm 9.9.1 disponibles en el entorno
- Estilos responsivos en SCSS

La compilación de producción se comprobó correctamente. Angular 13 no declara compatibilidad oficial con Node 18.20.8, aunque el build local funciona. No se modificaron las versiones globales instaladas.

## Iniciar en desarrollo

```bash
npm start
```

La aplicación se sirve en `http://localhost:4200/`.

## Compilar

```bash
npm run build
```

## Secciones

- Perfil y resumen profesional
- Experiencia en Editorial BookMaster
- CRM para restaurante
- Aplicación móvil de gestión escolar
- Tecnologías y prototipado con Figma
- Formación académica y certificaciones
- Contacto por correo, WhatsApp y LinkedIn
- Descarga del CV original en PDF

Los casos de estudio describen las funciones revisadas en los proyectos. La maqueta web de BookMaster y las pantallas del CRM son recreaciones para el portafolio con datos ficticios; no son capturas de los sistemas de producción.

## Flujo de ramas

- `main`: versión estable del portafolio.
- `dev`: integración de cambios en curso.
- `feature/nombre-breve`: nuevas secciones o mejoras, creadas desde `dev` y luego fusionadas de vuelta a `dev`.
